# Edge 검출, 영역 분할, 미분 필터

## 1. Edge 검출과 영역 분할의 중요성, 쌍대성

- 컴퓨터 비전에서 이미지를 이해하고 해석하기 위한 필수 두 축
- Edge 검출: 구조의 이해
  - 픽셀의 급격한 변화로 객체의 경계와 형태 파악
  - 이미지의 구조적 정보 추출에 핵심 역할
- 영역 분할: 의미의 해석
  - 유사한 특성의 픽셀을 집합으로 묶어 의미 있는 객체 단위로 분할
  - 장면의 구성과 의미 해석에 핵심 역할
- 상호 보완적으로 사용하면 인식 정확도 극대화
- 쌍대 문제(Dual Problem) 관계
  - Edge를 완벽히 검출해 폐곡선을 만들면 영역이 정의됨
  - 영역 분할이 완벽하면 경계면이 곧 Edge
  - 하나를 풀면 나머지가 해결되는 거울 같은 대응 구조

## 2. Edge와 영역의 정의 차이

- 두 개념은 영상을 바라보는 수학적 기준이 다름

| 구분 | Edge | Region(영역) |
|---|---|---|
| 기준 | 불연속성(Discontinuity) | 동질성(Homogeneity) |
| 접근 | 밝기나 색상이 급격히 변하는 국소 지점 탐색 | 인접 픽셀이 유사한 특성을 공유하면 하나의 집합으로 묶음 |
| 측정 방법 | 픽셀 값의 1차 또는 2차 미분 연산자, 미분 값이 임계값을 넘는 지점을 Edge로 간주 | 픽셀 간 유클리드 거리, 통계적 분포, 히스토그램 유사도 |
| 특징 | 물체와 배경의 경계 검출에 특화, 연산 속도 빠름, 노이즈에 취약 | 물체를 '닫힌 영역'으로 정의, 잡음 섞인 영상에서도 비교적 안정적 |
| 대표 기법 | Sobel, Canny, Prewitt | Region Growing, K-Means Clustering |

- 실제 영상처리 현장의 한계
  - Edge 정보만으로는 폐곡선을 완전히 얻기 어려움
  - 영역 정보만으로는 경계가 모호해지는 경우가 많음
- 보완 방식
  - Edge로 경계를 추정하고 영역 기반 방식으로 내부를 채우는 하이브리드 방식 사용

## 3. 영상처리에서 미분의 정의와 필터 컨볼루션 구현 원리

### 미분의 정의

- 인접한 픽셀 간 밝기 변화율을 측정하는 수학적 도구
- 연속 함수에서는 특정 지점의 기울기를 구하는 가장 기본적인 식
- 디지털 영상은 이산적인 픽셀로 구성되어 h를 0으로 보낼 수 없음
- 최소 단위 h=1을 가정하고 차분으로 변화 정도를 수치화

### 에지 검출용 미분 필터

- 필터(커널)로 차분 연산을 영상 전체에 효율적으로 적용
- 1차 미분 필터 [-1, 0, 1]
  - 변화의 유무와 크기(강도) 파악
- 2차 미분 필터 [1, -2, 1]
  - 변화의 곡률과 정확한 위치 파악
- 1차와 2차 미분 필터는 에지 검출과 해석에서 상호 보완 관계

### 필터 컨볼루션 구현 원리

- 수학적 미분 공식(차분 식)을 영상 전체에 효율적으로 적용하는 핵심 알고리즘
- 진행 과정: 슬라이딩, 가중치 합, 특징 맵 생성
  1. 슬라이딩(Sliding)
     - 필터를 좌측 상단부터 우측 하단까지 한 픽셀씩 이동
     - 영상의 국소 데이터(Local Neighbor)를 순차적으로 탐색
  2. 가중치 합 연산(Weighted Sum)
     - 필터의 각 가중치와 대응하는 영상 픽셀 값을 곱해 합산
     - 필터 가중치는 미분 공식의 계수(예: -1, 0, 1)와 동일
     - 슬라이딩은 곧 영상 전체에 미분 공식을 반복 적용하는 것과 같음
  3. 특징 맵 생성(Feature Mapping)
     - 각 위치의 결과값을 모아 새로운 출력 영상 생성
     - 명암 변화가 없는 곳은 0, 급격한 변화가 있는 에지 영역은 높은 값
