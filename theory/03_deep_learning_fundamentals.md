# 딥러닝 기초 이론

## 1. 수작업 규칙 기반 방식의 한계

- 기존 방식: 사람이 영상을 보고 직접 규칙을 도출해 프로그래밍
  - 대표 예: 모라벡 알고리즘, 해리스 특징점, SIFT, 매칭
  - 사람이 직접 도출한 규칙과 특징점 매칭에 의존
- 한계
  - 사람이 인지하고 정의할 수 있는 정보만 활용 가능, 복잡하고 다양한 영상 패턴 반영에 한계
  - 장면이 조금만 달라져도 규칙이 쉽게 깨져 일반화 어려움
  - 새로운 문제마다 추가 수작업 필요

## 2. 딥러닝의 장점과 양질의 데이터

- 딥러닝의 장점
  - 데이터와 정답을 바탕으로 중요한 특징과 최적의 필터를 모델이 스스로 탐색
  - 영상, 음성 등 복잡한 비선형 문제에서 사람이 인지하지 못하는 미세한 패턴까지 포착
  - 데이터가 축적될수록 성능이 지속 향상되는 확장성
- 양질의 데이터의 중요성
  - 딥러닝은 입력 데이터의 정확성, 다양성, 일관성에 의존해 패턴 학습
  - 데이터가 충분하고 다양한 상황을 포함할수록 특정 경우에 치우치지 않고 일반적인 규칙 학습
  - 데이터가 부족하거나 편향되면 실제 환경에서 일반화 성능 급감
  - 모델의 신뢰성과 최종 성능을 결정하는 핵심 요소

## 3. 퍼셉트론의 한계와 XOR 문제 해결

- 단층 퍼셉트론
  - 입력 신호의 가중합에 편향을 더한 값이 임계값을 넘는지 판단
  - 출력: 0(가중합 + 편향 < 0) 또는 1(가중합 + 편향 >= 0)
  - 기하학적으로 데이터 공간을 하나의 직선으로 구분하는 선형 분류기
- 한계
  - AND, OR 같은 선형 분리 가능 문제는 해결 가능
  - 하나의 직선으로 구분할 수 없는 XOR 같은 비선형 문제는 해결 불가
- 해결 방법: 다층 퍼셉트론(MLP)
  - 입력층과 출력층 사이에 은닉층 추가, 비선형 활성 함수 결합
  - 은닉층이 입력 공간을 선형 분리 가능한 새 표현 공간으로 변환
  - 복잡한 비선형 결정 경계 형성으로 XOR 해결

## 4. 손실 함수(Loss Function)

- 정의
  - 모델의 예측값과 실제 정답 사이의 오차를 수치로 나타낸 함수
  - 인공지능 학습은 이 값을 최소화하는 방향으로 진행
- 평균제곱오차(MSE)
  - 예측값과 정답의 차이를 제곱해 평균
  - 주로 회귀 문제에 사용
  - 오차가 클수록 패널티가 커지지만 이상치에 취약
- 교차 엔트로피 오차(CEE)
  - 예측 확률과 실제 정답 분포의 차이를 측정
  - 주로 분류 문제에 사용, 이진 분류와 다중 분류 모두 활용
  - 오답에 가깝게 예측할수록 손실 값이 급격히 증가해 강한 패널티 부여

## 5. 활성 함수(Activation Function)

- 정의
  - 신경망 각 노드에서 입력의 가중합에 편향을 더한 값을 비선형적으로 변환해 다음 층에 전달하는 함수
  - 핵심 목적: 신경망에 비선형성 부여
  - 활성 함수가 없거나 선형 함수를 쓰면 여러 층을 쌓아도 하나의 선형 연산으로 축소되어 복잡한 패턴 학습 불가
- 시그모이드
  - 출력을 0과 1 사이로 압축해 확률 해석에 유리
  - 층이 깊어질수록 기울기 소실 발생
- 하이퍼볼릭 탄젠트(Tanh)
  - 출력 범위 -1과 1 사이, 시그모이드보다 학습 속도 빠름
  - 양극단에서 기울기 소실 문제를 완전히 해결하지는 못함
- 렐루(ReLU)
  - 양수 구간에서 미분값을 일정하게 유지해 학습 속도가 빠르고 기울기 소실 문제를 구조적으로 해결
  - 음수 구간에서 출력이 0으로 고정되어 노드가 비활성화되는 'Dying ReLU' 현상 발생 가능

## 6. 경사하강법(Gradient Descent)의 원리

- 손실 함수 E(w)를 최소화하기 위해 기울기의 반대 방향으로 가중치를 반복 업데이트하는 최적화 기법
- 학습률 η: 한 번에 이동하는 크기 결정
- 배치 경사하강법(BGD)
  - 전체 데이터셋의 평균 기울기로 가중치 갱신
  - 수렴 경로가 안정적
  - 데이터가 많을수록 계산량과 메모리 사용량 증가
- 확률적 경사하강법(SGD)
  - 무작위로 선택한 하나의 데이터 기울기로 즉시 갱신
  - 연산 속도가 빠르고 메모리 부담이 적음
  - 기울기 계산에 노이즈가 포함되어 로컬 미니멈이나 안장점에서 벗어나는 데 유리할 수 있음

## 7. 역전파(Backpropagation)의 원리

- 출력층에서 발생한 오차를 입력층 방향으로 거꾸로 전파하며 각 가중치에 대한 오차 기울기를 효율적으로 계산하는 알고리즘
- 합성함수 미분 원리인 연쇄 법칙(Chain Rule) 기반
  - 출력층부터 앞쪽 층까지 국소 미분값을 차례로 곱해 나감
  - 최종 오차가 각 가중치에 미치는 영향을 역추적
- 단일 가중치의 오차 기울기
  - 출력 오차, 현재 노드 활성 함수의 미분값, 직전 노드가 전달한 입력값의 곱
- 효율성
  - 뒤쪽 레이어의 연산 결과가 앞쪽 레이어의 기울기 계산에 재사용
  - 수천만 개 가중치를 가진 심층 신경망에서도 중복 계산 없이 수치 미분 대비 효율적으로 학습

## 8. 역전파에서의 연쇄 법칙(Chain Rule)

- 합성함수의 미분을 각 개별 함수 미분값의 곱으로 분해하는 미적분학의 기본 원리
- 인공신경망은 노드와 가중치가 층층이 연결된 거대한 합성함수 구조
  - 출력층의 오차를 앞쪽 가중치까지 전달해 업데이트하려면 연쇄 법칙이 필수
- 역전파는 이 원리로 출력층에서 입력층 방향으로 거슬러 오르며 각 지점의 국소 미분값을 차례로 곱함
- 이미 계산된 뒤쪽 층의 오차 미분값을 앞쪽 층의 기울기 계산에 재사용
  - 깊은 신경망에서도 중복 연산 없이 모든 가중치의 기울기 계산 가능

## 9. 최적화(Optimization)

- 정의
  - 손실 함수를 최소화하는 최적의 가중치와 편향을 찾는 과정
  - 계산된 기울기 정보로 가중치를 어느 방향으로 얼마만큼 이동시킬지 결정
- 모멘텀(Momentum)
  - 경사하강법에 관성 개념 도입, 직전 이동 방향 반영
  - 학습 속도 향상, 로컬 미니멈이나 안장점 탈출에 도움
- 아다그라드(AdaGrad)
  - 가중치마다 학습률을 다르게 적용
  - 자주 업데이트되는 가중치는 보폭을 줄이고, 덜 업데이트되는 가중치는 보폭을 크게 유지
  - 학습이 오래될수록 학습률이 지나치게 작아질 수 있음
- 아담(Adam)
  - 모멘텀의 관성과 아다그라드의 적응형 학습률을 결합
  - 안정성과 효율성을 동시에 갖춰 현대 딥러닝에서 널리 사용

## 10. 하이퍼파라미터(Hyperparameter)

- 정의
  - 사용자가 학습 전에 직접 설정하는 외부 매개변수
  - 데이터로부터 자동 학습되는 가중치 및 편향과 구분
  - 모델 성능과 과적합 여부를 좌우하므로 하이퍼파라미터 튜닝 필수
- 학습률
  - 가중치 갱신 보폭
  - 너무 크면 발산, 너무 작으면 학습 정체
- 배치 크기
  - 1회 학습 시 데이터 단위
  - 크면 안정적이지만 메모리 부담, 작으면 연산은 빠르나 수렴 불안정
- 에포크
  - 전체 데이터의 반복 학습 횟수
  - 부족하면 과소적합, 과하면 과적합
- 은닉층 수와 노드 수
  - 모델의 표현 능력 결정
  - 많을수록 복잡한 패턴 학습 가능, 계산량 증가와 과적합 위험 동반

## 11. 인공지능 학습 과정: 손실, 미분, 역전파, 최적화

### 손실 계산

- 예측값과 정답의 오차를 정의하는 손실 함수 계산에서 학습 시작
- 예: 정답 3, 모델 예측 8이면 오차 5, 오차가 클수록 손실 값도 커짐
- 학습의 목표: 손실을 최소화하는 가중치 탐색
- 가중치: 신경망 각 연결에 부여된 수치, 입력 신호가 다음 층에서 얼마나 중요하게 반영될지 결정
- 학습은 가중치를 조금씩 조정해 나가는 과정

### 미분

- 손실은 가중치로 이루어진 함수
  - 가중치가 바뀌면 예측값과 손실도 함께 변화
- 손실을 가중치로 미분하면 가중치 변화에 따른 손실 변화량 파악 가능
  - 가중치를 어느 방향으로 얼마나 조정할지 결정 가능
- 비유: 산에서 내려갈 때 경사가 오른쪽으로 올라가 있으면 왼쪽으로 내려가듯, 기울기의 반대 방향으로 이동

### 역전파

- 문제: 심층 신경망은 수천만 개 가중치가 수십 개 층에 얽혀 있어 가중치별 기울기를 하나씩 직접 계산하면 비효율적
  - 가중치 하나를 평가할 때마다 전체를 다시 계산해야 함
- 해결: 역전파 알고리즘
  - 출력층의 오차를 입력층 방향으로 거꾸로 전달
  - 연쇄 법칙으로 각 층의 국소 미분값을 차례로 곱함
- 가중치 하나의 기울기 구성
  - 출력값이 손실에 미치는 영향
  - 활성 함수 입력이 출력에 미치는 영향
  - 가중치가 활성 함수 입력에 미치는 영향
- 뒤쪽 층의 미분값을 앞쪽 층에서 재사용해 한 번의 역방향 패스로 모든 가중치의 기울기 계산

### 최적화

- 구한 기울기로 최적화 알고리즘이 가중치 업데이트
  - 갱신식: 새 가중치 = 기존 가중치 - 학습률 × 손실의 기울기
- 손실이 감소하는 방향, 즉 기울기의 반대 방향으로 학습률만큼 반복 이동
- SGD, Adam 등이 학습률 조절이나 이동 방향 보정으로 손실을 더 빠르고 안정적으로 감소

### 요약

- 손실 계산, 미분 기반 방향 파악, 역전파를 통한 기울기 계산, 최적화 기반 가중치 갱신의 반복
- 수학적 피드백 루프를 반복해 최적의 가중치 탐색
